## 🌟 About the Project

This project started as a simple static portfolio and evolved into a **fully functional, production-ready Next.js 14 Web Application**. It acts as both a breathtaking showcase of microscopic art carved on graphite and a seamless e-commerce store.

### ✨ Key Features
- **Premium User Experience**: Designed with luxury aesthetics, featuring glassmorphism, dynamic image cross-fading, and a custom interactive canvas "glitter trail" that follows your cursor.
- **Dynamic GitHub Gallery**: The gallery automatically fetches and renders images directly from this repository using the GitHub API—meaning I can update my portfolio just by dropping new images into the `public/assets` folder.
- **Secure Authentication**: Full user login, signup, and profile management powered by Supabase.
- **E-Commerce Ready**: Includes a Cart, Wishlist, and an Order History system.
- **Integrated Payments**: Fully integrated with Razorpay for secure advance payments.
- **WhatsApp Integration**: Real-time order notifications sent directly to my WhatsApp to streamline customer communication.

## 💻 Technical Stack

This application is built with modern, scalable web technologies:

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Frontend**: [React 18](https://react.dev/), Vanilla CSS (Custom Design System, no UI libraries)
- **Backend & Auth**: [Supabase](https://supabase.com/) (PostgreSQL, Row Level Security, SSR Auth)
- **Payments**: [Razorpay](https://razorpay.com/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Version Control**: Git & GitHub

## 🚀 Getting Started (For Students/Developers)

If you'd like to run this project locally to see how it works:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ponmudii/pencil_._carving.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Set up Environment Variables:**
   Create a `.env.local` file in the root directory and add your keys (Supabase, Razorpay, GitHub config).
4. **Run the development server:**
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
